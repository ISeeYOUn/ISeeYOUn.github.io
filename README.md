# Two Truths and a Lie — AWS Edition 🎴

An interactive web application featuring flip cards about AWS, Cloud Computing, and Women in Tech in India.

## 🚀 Features

- **Interactive Flip Cards**: Enter a card number or browse the deck to view AWS concepts and reveal statements.
- **Two Truths & a Lie**: Test your knowledge by guessing the lie among AWS cloud architecture, service facts, and tech trivia.
- **Timer Challenge**: Beat the 2-minute countdown timer while evaluating the card statements.
- **Rich Visuals**: Custom flip card illustrations and modern dark-mode UI with smooth micro-animations.

## 📁 Project Structure

- `index.html` - Main flip card interactive deck and quiz game.
- `deep.html` - Enhanced number card selection mode with timer and image reveals.
- `AWS/` - Card assets and visual illustration deck (Cards 1–100+).

## 🛠️ Getting Started

Open `index.html` or `deep.html` directly in any modern web browser.
